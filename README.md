## Получить access token для авторизации через itellij idea

Первым делом надо получить из идеи доступ до вашего аккаунта на гите, чтобы была возможность создавать репозитории и пушить в них прямо из среды разработки. [Как получить access token](https://www.geeksforgeeks.org/git/how-to-generate-personal-access-token-in-github/)

# Инструкция по сдаче ДЗ
## Какие файлы требуется выложить на гит?
- Вся папка src
- Файл gitinore. [Что это за файл и зачем он нужен](https://purpleschool.ru/knowledge-base/git/basics/gitignore)
- Readme файл, в котором вы пишите текст задания и кратко, что вы сделали. [А это то зачем надо?](https://blog.skillfactory.ru/readme-md-github/)

## Достаточно ли просто выложить код в репозиторий? Дисклеймер - нет, не достаточно
Для сдачи вам требуется создать pull request (PR, MR, merge request - все про одно). [Пример](https://github.com/SofChernikova/demo-pull-request/pull/1/changes)

[Как создать пул реквест](https://blog.skillfactory.ru/pull-request-v-github/)
